# TumorHoPe: A Database of Tumor Homing Peptides

Welcome to the official repository and documentation overview for **TumorHoPe**, a manually curated catalog of experimentally validated peptides that specifically recognize tumor cells and tumor-associated microenvironments (angiogenesis). This resource provides a specialized platform for researchers to explore targeted drug delivery vehicles and imaging systems.

**Web Server:** [http://crdd.osdd.net/raghava/tumorhope](http://crdd.osdd.net/raghava/tumorhope)

## About the Database

TumorHoPe is a comprehensive resource developed to assist the scientific community in identifying peptides capable of homing into tumor tissues with high specificity. These peptides are playing a vital role in delivering drugs and nanoparticles to tumors while sparing normal tissues.

The database integrates data from:
* **Primary Literature:** 359 peptides manually curated from research papers.
* **Patents:** 253 peptides sourced from international patent databases.
* **Common Data:** 132 peptides found in both literature and patents.


## Key Features

### Comprehensive Dataset
* **744 unique peptides** with experimentally validated homing capabilities.
* **Target Diversity:** Covers 20+ tumor types and 72+ cancer cell lines (e.g., MDA-MB, MCF-7, SK-BR-3).
* **Validation Details:** Information on *in vivo* (phage display) and *in vitro* validation methods.

### Built-in Tools
* **Peptide Mapping:** Map known tumor homing peptides onto user-defined protein sequences.
* **Customized BLAST & Smith-Waterman:** Search for homologous peptides using optimized algorithms for short sequences.
* **Search & Browse:** Query by target tumor, cell line, or amino acid composition.



## Overview

TumorHoPe provides both primary and derived information for every entry:
1.  **Primary Data:** Peptide sequence, target organ, cell line, and identification techniques.
2.  **Structural Data:** Secondary structure assignments via **DSSP** and 3D models predicted by **PEPstr**.
3.  **Physicochemical Properties:** Molecular weight, isoelectric point (pI), and net charge.
4.  **Motif Analysis:** Identification of frequent motifs like **RGD** (36 peptides) and **NGR** (45 peptides).



## Applications

* **Targeted Therapy:** Developing peptide-drug conjugates (PDCs) for specific tumor delivery.
* **Molecular Imaging:** Utilizing THPs as probes for non-invasive tumor detection.
* **Peptide Engineering:** Analyzing amino acid preferences (e.g., high Cys and Arg content) to design novel synthetic homing peptides.
